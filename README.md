# Bozkurt Robotik Website

Static corporate website for Bozkurt Robotik.

## Deployment
This repository is designed to deploy directly on Cloudflare Pages.

Recommended settings:
- Framework preset: None
- Build command: leave empty
- Build output directory: /
- Production branch: main

## Files
- index.html
- styles.css
- script.js
- assets/bozkurt-robotik-logo.png

## Notes
Product photo areas are placeholders by design and should be replaced after professional photography.
